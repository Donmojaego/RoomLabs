ANIMATION NOTE
Read ANIMATION_NOTE_FR.txt. The mechanisms should be animated as separate
moving parts with fixed pivots and a smooth loop. Interlocking gears should
rotate in mechanically correct opposite directions.

DESIGN NOTES
Palette: deep petrol teal, antique brass, burgundy enamel, ivory and warm amber.
Use the main interface plate as the base skin. Place the isolated controls and
ornaments over the matching wells. Blank plates are intended for editable labels.
Sprite sheets can be cropped into individual controls for implementation.
