# African Riddim {{VERSION}} — Windows

54 instruments d'Afrique sur une carte interactive, par Room Labs Audio (VST3 + application autonome).

## Installer
- **Installeur** : lancer `AfricanRiddim-Setup-{{VERSION}}.exe`.
- **À la main** : copier `African Riddim.vst3` dans `C:\Program Files\Common Files\VST3\`.

Dans FL Studio : Options > Manage plugins > Find installed plugins, puis Ajouter > African Riddim (Generators).

## Contenu
- `African Riddim.vst3`, `African Riddim.exe`
- `RAPPORT-TESTS.md` : résultats des tests automatiques de cette version
- `A-FAIRE.md` : ce qui reste à vérifier
