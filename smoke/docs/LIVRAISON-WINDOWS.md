# Smoke {{VERSION}} — Windows

Claviers, nappes, risers et basses pour le R&B, le hip-hop et la house, par Room Labs Audio (VST3 + application autonome).

## Installer

- **Installeur** : lancer `Smoke-Setup-{{VERSION}}.exe`.
- **À la main** : copier `Smoke.vst3` dans `C:\Program Files\Common Files\VST3\`.

Dans FL Studio : Options > Manage plugins > Find installed plugins, puis Ajouter > Smoke (Generators).

## Emplacements

| Quoi | Où |
|---|---|
| Plugin | `C:\Program Files\Common Files\VST3\Smoke.vst3` |
| Application autonome | `C:\Program Files\Smoke\Smoke.exe` |
| Presets d'usine | intégrés au plugin (copie : `C:\Program Files\Smoke\Presets\factory.json`) |
| Préférences d'interface | `%APPDATA%\Room Labs\Smoke\Smoke.settings` |

## Contenu du dossier

- `Smoke.vst3`, `Smoke.exe`
- `RAPPORT-TESTS.md` : résultats des tests automatiques de cette version
- `A-FAIRE.md` : ce qui reste à vérifier

## Tester

1. Choisir une banque (KEYS, RHODES, RISERS, SUB) et jouer : la braise s'allume, la fumée monte avec le son et se dissipe à la relâche.
2. Monter SPACE, DREAM et MOD, baisser CLEAN : les yeux rougissent et se troublent.
3. Choisir un accord (m9, maj9…) : une touche joue l'accord entier.
4. Icône égaliseur : réglages du son. Roue : thème Prune / Bleu / Vert, taille, animation. F2 : fluidité de l'animation.
